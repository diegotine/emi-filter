# Inventário de licenças declaradas pelas dependências Rust

Gerado de `cargo metadata --locked --offline --format-version 1 --filter-platform`
para `x86_64-unknown-linux-gnu` e `x86_64-pc-windows-gnu`, em 20/10/2026.
São 219 pacotes distintos resolvidos para os dois alvos. Este inventário inclui
dependências de compilação e pacotes resolvidos; não identifica quais objetos
foram efetivamente retidos pelo linker em cada executável.
Os textos encontrados nos pacotes do cache Cargo foram copiados sem alteração.
Quando nenhum texto de licença veio no pacote, a tabela conserva a declaração
SPDX e o endereço upstream; não inventa avisos de copyright.
Para a família egui 0.31.1, os textos comuns também estão em
[LICENSE-MIT](egui-0.31.1/LICENSE-MIT) e [LICENSE-APACHE](egui-0.31.1/LICENSE-APACHE).
